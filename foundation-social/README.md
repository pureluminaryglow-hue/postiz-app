# Marion Hughes Foundation — Social Media Operations

**Brand owner:** Marion Hughes Foundation  
**Flagship project:** Brandon's Home  
**Public contact:** brandonshome@marionhughesfoundation.co.site  
**Timezone:** Africa/Johannesburg

This folder is an editorial and operational starter pack for the Postiz installation in this repository. It is **not** a deployed Postiz instance, does **not** create social-media accounts, and does **not** grant access to social platforms.

## Mission
Advocate for sustainable, safe, dignified and meaningful adult lives for autistic people in South Africa. Brandon's Home is the planned first supported-living pilot, combining individualized support, safety, chosen activities, and opportunities to participate and contribute according to each resident's interests and abilities.

## Brand hierarchy
- Primary account name: **Marion Hughes Foundation**
- Programme identifier: **Brandon's Home | A Marion Hughes Foundation Project**
- Prefer `@MarionHughesFoundation` when available; otherwise `@MarionHughesFdn` or `@MHFAutism`. All handles require an availability check.
- Do not assert that the Foundation is formally registered until registration is complete. Do not claim PBO status or Section 18A tax deductibility without approvals.
- Do not imply Brandon's Home has already opened, residents have been accommodated, property acquired, or construction started.
- Donation CTA: **Support Brandon's Home through the existing BackaBuddy campaign**, using its verified exact URL. Do not publish a guessed URL.

## Editorial standards
1. Be accurate about planning, fundraising and registration status; distinguish aspirations from milestones achieved.
2. Use respectful, neurodiversity-affirming wording, acknowledge a range of support needs, and seek autistic input.
3. Obtain appropriate consent for identifiable images, video, stories and personal information; never post distressing footage for engagement.
4. Never fabricate testimonials, beneficiary outcomes, donation totals, sponsor relationships or urgency.
5. Include captions, alt text, readable contrast and accessible wording.
6. Use a review-before-publish workflow until accounts and legal disclosures are verified.
7. Respond to respectful disagreement; remove scams, harassment, personal information leaks and threats.

## Postiz publication workflow
**Idea → factual verification → consent check → draft → asset approval → platform adaptation → human approval → schedule → monitor → report.**

Use platform-specific creative ratios and character limits. Store media outside GitHub when it contains sensitive information. Keep API credentials, OAuth tokens and Postiz API keys exclusively in a secret manager or environment configuration, never in this public repo.
